# تقرير تحقق تطبيق المدينة إكسبرس — 2.9.2

تاريخ المراجعة: 2026-09-05.

## تغييرات المصدر

- رقم الإصدار 34 واسم الإصدار 2.9.2، مع اللاحقة `-test` لبناء Debug.
- إزالة خانة الكود من صفحة الإنشاء ومن نموذج بيانات الإنشاء. يُرسل الطرد الجديد برقم تتبع فارغ إلى `POST /api/almadina/orders`، ثم تفتح صفحة تفاصيله بعد استجابة نجاح مؤكدة.
- يحتفظ نموذج الإنشاء بمعرّف الطرد عبر إعادة تركيب الواجهة واستعادة حالتها، ويعيد الطلب بهذا المعرّف نفسه عند تعذّر تأكيد الاستجابة. تؤكد واجهة الخادم إنشاء المعرّف المطلوب قبل الانتقال.
- استبدال خانة الكتابة وزر حفظ الكود في التفاصيل بزر «إضافة كود QR» يفتح Google Code Scanner الموجود في التطبيق، لصاحب الطرد أو المسؤول فقط. تُرسل نتيجة المسح تلقائيًا إلى `POST /api/almadina/orders/assign-code` مع `orderId` و`trackingNumber` لربطها بالطرد المفتوح.
- لا تمر نتيجة المسح عبر البحث العام أو تحويل حالة الشحن. عند رفض الطلب أو تعذّر الاتصال يبقى الكود المقروء ظاهرًا دون تحرير، ويمكن إعادة الحفظ أو قراءة QR آخر. لا يظهر الكود محفوظًا حتى يؤكده الخادم.
- يُمنع فتح أكثر من قارئ في الوقت نفسه، وتُفرّغ نتيجة المسح بعد النجاح أو الإلغاء أو الخطأ. تظهر رسالة عند تعذّر تشغيل القارئ، وتُهمل النتيجة إذا تغيّر الحساب أو انتهى عمر شاشة Android الرئيسية. إلغاء الكاميرا لا يرسل طلب ربط.
- لا يمكن استبدال كود موجود. الطرد المحذوف يحتاج الاستعادة قبل إضافة كود QR. منع تكرار الأكواد بين الحسابات وحجزها نهائيًا مسؤولية الخادم المرافق.
- تعطيل نسخ الرقم وعرض QR عندما لا يوجد كود محفوظ. تظهر «بانتظار إضافة كود QR» في قوائم الطرود وعنوان التفاصيل. لا تطابق خانة المسح الفارغة طردًا بدون كود.
- الحفاظ على حجز دفعات الملصقات للإدارة وطباعتها أو حفظها PDF: من 1 إلى 500 كود، 24 ملصقًا لكل صفحة A4، مع QR ورقم مقروء، وتحديث الاستخدام قبل الطباعة. بقي حفظ طلب الحجز المشفّر وإعادة المحاولة بالطلب نفسه كما في 2.9.0.

## المراجعة التي أُجريت

رُوجعت تواقيع Compose وViewModel ومسار النتيجة من الكاميرا إلى صفحة التفاصيل، وحالات الإلغاء وفشل القراءة وإعادة المحاولة، والانتقال بعد الإنشاء المؤكد وعدم توليد QR لكود فارغ. هذه مراجعة مصدر وليست ترجمة ناجحة أو اختبارًا على جهاز.

نجح بناء الموقع المرافق v35 وفحص TypeScript وLint و86 اختبارًا. شملت الاختبارات توليد QR من دفعة محجوزة وفكّه برمجيًا وربطه بالطرد المختار، وإعادة إرسال الكود دون تكرار، ورفض ربطه بطرد آخر، وصلاحيات الربط والتزامن. كما اختُبرت واجهة الموقع المولّدة للتأكد من غياب الكتابة اليدوية في التفاصيل والماسح المخصص للربط.

لم تُجرَ تجربة جهاز أو طباعة أو كاميرا أو بصمة لهذا الإصدار، ولم تُنشأ دفعات أو طرود في قاعدة الموقع الحي.

## حالة البناء الفعلية

أُجريت محاولة بناء لهذا الإصدار باستخدام JDK 17 وGradle 8.13 وAndroid SDK المحلي، دون تنزيل اعتماديات، بالأمر:

```bash
gradle --offline --no-daemon --max-workers=2 -Pkotlin.compiler.execution.strategy=in-process :app:assembleDebug :app:lintDebug
```

توقفت المحاولة قبل ترجمة Kotlin عند حل اعتماديات `checkDebugDuplicateClasses`، لأن Gradle لم يجد الاعتماديات الآتية في ذاكرته للعمل دون اتصال:

- `androidx.lifecycle:lifecycle-common-java8:2.9.2`
- `androidx.concurrent:concurrent-futures-ktx:1.1.0`
- `androidx.room:room-common:2.6.1`
- `androidx.concurrent:concurrent-futures:1.1.0`
- `com.google.zxing:core:3.5.4`
- `com.google.firebase:firebase-annotations:16.0.0`

لم تنجح ترجمة Kotlin أو Android Lint لهذا المصدر، ولم يُنتَج APK أو AAB جديد للإصدار 2.9.2. لا يُعد أي ملف بناء قديم نسخة مطابقة لهذا المصدر.

## استكمال البناء والتفعيل

افتح المشروع في Android Studio مع JDK 17 وAndroid SDK Platform 36 وBuild Tools 36.0.0، وانتظر اكتمال Gradle Sync وتنزيل الاعتماديات، ثم نفّذ:

```bash
./gradlew --no-daemon --max-workers=2 -Pkotlin.compiler.execution.strategy=in-process :app:assembleDebug :app:lintDebug
```

بعد نجاح البناء يظهر APK التجريبي في `app/build/outputs/apk/debug/app-debug.apk`. يتطلب تحديث نسخة مثبتة استخدام مفتاح التوقيع نفسه، وتحتاج نسخة النشر إلى توقيع مالك التطبيق.

استخدم خادم الموقع المرافق v35؛ يستخدم الربط مسار `POST /api/almadina/orders/assign-code` الذي أُضيف في v34. إذا كان الخادم أقدم من v34 فيجب تحديثه قبل التطبيق. لا يتطلب هذا التغيير جدول SQL جديدًا، وتبقى قاعدة البيانات الحالية وإعدادات الخدمة محفوظة. بعد نجاح البناء يلزم اختبار قراءة الملصق بالكاميرا وإلغاء المسح ورفض كود مستخدم وإعادة الحفظ عند انقطاع الاتصال على جهاز فعلي. تفاصيل الاستخدام في `README-AR.md`.
