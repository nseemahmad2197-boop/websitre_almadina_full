# التحقق من نقلة Monorepo — 2026-09-10

| الفحص المنفّذ | النتيجة وحدودها |
|---|---|
| مقارنة حزم الأساس | نُقلت جميع الملفات الأصلية: الموقع 123، Android 67، وiOS 59؛ لا ملفات أصلية مفقودة. |
| مقارنة ملفات تشغيل التطبيقات | الاختلافات في ثلاثة ملفات تسعير هي تعليقات المولّد والمسافات فقط؛ القيم والدوال الأصلية محفوظة. أضيفت أدوات واختبارات ووثائق حول المشاريع. |
| بناء الموقع من `apps/web` | ناجح، باستخدام نفس package-lock واعتمادات الموقع v45. |
| اختبارات الموقع السابقة | 119 ناجحة، وتشمل وظائف API والفواتير والصلاحيات والسحب والحذف والجلسات. |
| اختبار التعرفات الفعلي في TypeScript | اختباران ناجحان؛ يغطيان القيم الـ18 وتعرفة المحافظات وحالة عدم تحديد المنطقة. |
| اختبارات أدوات المستودع | 12 ناجحة؛ تشمل كشف اختلاف المخرجات، تعديلًا تجريبيًا في نسخة مؤقتة، الأرقام غير الصالحة، فقدان علامات التوليد، وانتقاء المنصات عند نقل الملفات أو فقدان تاريخ Git. |
| منطق Android المكتوب بـKotlin | ترجمة ناجحة للملفات الأساسية المستخدمة في الاختبارات، و17 اختبار JUnit ناجحًا، تشمل التسعير وسلامة الجلسات وحذف الحساب وإخفاء الفواتير. |
| فحوص مصدر iOS | 50/50 ناجحة، بما فيها سلامة مراجع Xcode. هذه فحوص ثابتة وليست بناء Swift أو اختبار جهاز. |
| إعدادات CI وRender | YAML صالح؛ تغيير إعداد Render مقتصر على `rootDir` و`autoDeployTrigger` مع إضافة تعليق توضيحي. لا تغيير لتعريف قاعدة البيانات أو متغيرات البيئة الموروثة. |

لم يُنفّذ في هذه البيئة: بناء Android كامل باستخدام Gradle وSDK، بناء iOS باستخدام Xcode، اختبارات المحاكي أو الجهاز، أو وظائف GitHub Actions. أُعدّ workflow لتشغيل بناء المنصات والاختبارات في بيئاتها المناسبة بعد رفع المستودع. اختبارات iOS الموجودة، وعددها 52 للوحدات و19 للواجهة، محفوظة ولم تُحتسب كاختبارات منفّذة هنا.

لا تتضمن النتائج اختبار اختراق جديدًا أو اختبار أحمال على الإنتاج. حزمة الموقع v45 تحتفظ بإصلاحات الاعتمادات الأمنية السابقة لأن `package.json` و`package-lock.json` لم يتغيرا. لم تُعدّل قاعدة بيانات الإنتاج أو نطاق الموقع أو توقيع التطبيقات، ولم يُجر نشر خارجي.

المصدر المشترك الحالي يغطي رسوم التوصيل الأساسية والراجع فقط. سياسة الخصوصية والواجهات وإدارة الأذونات وتنفيذ تسجيل الدخول لا تصبح كودًا مشتركًا بين Swift وKotlin وTypeScript بمجرد وجودها في مستودع واحد. أي تغيير لاحق فيها يحتاج مراجعة وتنفيذًا واختبارًا بحسب كل منصة.
