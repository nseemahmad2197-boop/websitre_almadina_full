# التحقق — هياكل حسابات الفريق

نجح TypeScript والبناء الإنتاجي، ونجح اختبار المتصفح `tests/role-loading.browser.mjs` واختبار انحدار `tests/page-loading.browser.mjs`.

استُخدم التطبيق الفعلي مع استجابات API محلية تجريبية، بحسابات مسؤول ومندوب وتاجر. غطّى الفحص استعادة تبويبات الإدارة الأربعة، رئيسية المندوب، طرود الفريق وتفاصيل المتابعة، ومقارنة الحالات المحمّلة وهياكلها عند 390 و1280، مع فحص عدم تجاوز العرض عند 320.

تأكد الفحص من بقاء عدد الإحصاءات المستجيبة مطابقًا، وزري الموظف في صف واحد، واختلاف الفلاتر، وعرض التفاصيل. راجعت الصور النهائية مقابل المحتوى. استمر التحديث الدوري والعودة إلى التبويب دون مؤشر متكرر أو هيكل فوق المحتوى الموجود، وبقيت عناصر الهياكل غير تفاعلية.

الصور تحمل لاحقة `loading` قبل وصول الاستجابة و`loaded` بعد وصولها. عدد الصفوف تجريبي؛ لا يدّعي الهيكل معرفة عدد النتائج قبل الاستجابة.

لم يُنشر الموقع الحي أو تُستخدم حسابات إنتاج. السجلات والبصمات في هذا المجلد تخص المصدر النهائي.
